# Cereza Presentaciones para Windows

Convierte los PDF del cotizador compatible en presentaciones de PowerPoint con el diseño Cereza. La aplicación funciona sin conexión después de descargarla.

## Descargar la versión 0.1.14

- [Instalador para Windows de 64 bits](https://github.com/esdrasbasurto6-afk/Cereza-Presentaciones-Descargas/releases/download/v0.1.14/Cereza-Presentaciones-Setup-0.1.14-Windows-x64.exe). Cierra Cereza Presentaciones si está abierta, ejecuta Setup y sigue el asistente.
- [Portable para Windows de 64 bits](https://github.com/esdrasbasurto6-afk/Cereza-Presentaciones-Descargas/releases/download/v0.1.14/Cereza-Presentaciones-0.1.14-Windows-x64.exe). Descarga y abre el archivo directamente.
- [Página de la versión](https://github.com/esdrasbasurto6-afk/Cereza-Presentaciones-Descargas/releases/tag/v0.1.14).

Los dos ejecutables ofrecen las mismas funciones. Los archivos de código fuente que genera GitHub contienen las instrucciones de este repositorio.

## Uso

1. Selecciona el PDF original descargado del cotizador compatible.
2. Revisa los productos, importes y diapositivas. Si los totales impresos y calculados difieren, elige cuál usar.
3. En la última diapositiva, **Contacto → Editar firma** permite cambiar nombre, celular y QR. Puedes elegir un archivo PNG o JPG.
4. Pulsa **Generar presentación** y elige dónde guardar el PowerPoint.

La versión 0.1.14 mejora la extracción de fotos grandes y deja editables los textos de **Condiciones**, **Política de Envío** y **Contacto**. La aplicación procesa los documentos localmente. Abre el archivo exportado con PowerPoint o LibreOffice.

Los ejecutables carecen de firma digital. Las versiones anteriores están en [Releases](https://github.com/esdrasbasurto6-afk/Cereza-Presentaciones-Descargas/releases).
