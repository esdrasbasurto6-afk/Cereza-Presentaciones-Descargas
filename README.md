# Cereza Presentaciones para Windows

[Descargar la versión 0.1.6](https://github.com/esdrasbasurto6-afk/Cereza-Presentaciones-Descargas/releases/tag/v0.1.6).

## ¿Qué archivo descargo?

- [Instalador Setup (recomendado)](https://github.com/esdrasbasurto6-afk/Cereza-Presentaciones-Descargas/releases/download/v0.1.6/Cereza-Presentaciones-Setup-0.1.6-Windows-x64.exe): asistente en español, accesos directos y desinstalador.
- [Portable sin instalación](https://github.com/esdrasbasurto6-afk/Cereza-Presentaciones-Descargas/releases/download/v0.1.6/Cereza-Presentaciones-0.1.6-Windows-x64.exe): guarda el archivo en una carpeta permanente y ábrelo directamente.

Windows de 64 bits. No requiere Node.js ni npm y funciona localmente sin internet. Los ejecutables no tienen firma digital.

## Uso

1. Instala el programa con Setup o abre el portable.
2. Selecciona el PDF del cotizador compatible.
3. Revisa los productos y recorre la vista previa. Desde cada producto puedes editar textos y precios.
4. En Precios e IVA puedes definir porcentaje, activar/desactivar IVA, aplicar descuento fijo o porcentual y cargos adicionales. Los totales se actualizan al aplicar los cambios.
5. Pulsa Generar presentación y elige dónde guardar el PowerPoint (.pptx).

## Novedades de 0.1.6

- Edición de textos y precios desde la vista previa.
- Actualización automática de subtotales y total general.
- IVA configurable, descuentos y cargos/envío, con opción de IVA sobre los cargos.
- Comparación con importes originales y vista del cálculo antes de aplicar.
- Restauración de precios por producto o de toda la cotización, conservando los textos ya aplicados.
- Generación directa, sin pantalla intermedia, y selección visible de otro PDF.

Los precios unitarios incluyen decorado y se consideran anteriores al IVA añadido en el resumen. El porcentaje inicial se calcula de los importes del PDF cuando es posible; puedes corregirlo o desactivar IVA. Las diferencias originales se conservan como ajustes visibles que conviene revisar.

El programa no modifica el PDF, no utiliza OCR y no admite cualquier diseño de cotización. Continúa en desarrollo: falta validar PDF multipágina reales del proveedor. Para abrir el PPTX guardado utiliza PowerPoint o LibreOffice; no los necesitas para generar ni previsualizar. Guarda tus documentos fuera de la carpeta del programa.

## Actualizar y desinstalar

Cierra la aplicación y ejecuta el nuevo Setup para actualizar. Si utilizas el portable, sustituye el ejecutable anterior. Para desinstalar usa Aplicaciones instaladas de Windows.
