# Cereza Presentaciones para Windows

Descarga el programa desde [la versión 0.1.3](https://github.com/esdrasbasurto6-afk/Cereza-Presentaciones-Descargas/releases/tag/v0.1.3).

## ¿Qué archivo descargo?

- **Cereza-Presentaciones-Setup-0.1.3-Windows-x64.exe**: instalador recomendado para uso diario. Incluye asistente en español, accesos directos y desinstalador.
- **Cereza-Presentaciones-0.1.3-Windows-x64.exe**: portable. Guárdalo en una carpeta y ábrelo directamente, sin instalación.

Ambas opciones son para Windows de 64 bits y funcionan localmente sin internet. No requieren Node.js ni npm. Los ejecutables no tienen firma digital.

## Instalación y uso

1. Descarga y ejecuta el archivo **Setup**.
2. Sigue el asistente y abre Cereza Presentaciones desde el escritorio o menú Inicio.
3. Selecciona un PDF con el formato del cotizador compatible.
4. Revisa los productos y recorre la vista previa.
5. Guarda tu presentación PowerPoint (.pptx).

El programa no admite cualquier formato PDF ni utiliza OCR. Para abrir los PPTX guardados necesitas PowerPoint o LibreOffice; no se requieren para generarlos ni previsualizarlos. Guarda tus documentos fuera de la carpeta del programa.

Para actualizar, cierra el programa y ejecuta el nuevo instalador. Para desinstalar, usa Aplicaciones instaladas de Windows. Si utilizas el portable, sustitúyelo por la versión nueva o borra el ejecutable para retirarlo.

Este repositorio distribuye únicamente instaladores, portables e instrucciones. No contiene el código fuente del proyecto ni documentos de clientes. Los archivos Source code que GitHub muestra automáticamente contienen solo el contenido público de este repositorio.
